# Breast Cancer Detection from Blood Samples
Machine learning pipeline for binary classification of breast cancer from routine blood test data 
(116 samples: 64 cancer, 52 healthy; 9 features). 
Covers: EDA, preprocessing, feature selection/reduction (Kruskal-Wallis, ROC-AUC, PCA, LDA)
and comparison of multiple classifiers (MDC, Bayesian, kNN, SVM, Decision Tree, AdaBoost, Random Forest).
